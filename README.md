# 🚢 Titanic: Machine Learning from Disaster

This project is a comprehensive data analysis and predictive modeling task based on the famous **Titanic dataset**. The goal is to analyze passenger data and build a machine learning model that predicts whether a passenger survived the shipwreck.

---

### 📊 Project Workflow

1.  **Exploratory Data Analysis (EDA):** Visualizing distributions, correlations, and survival rates based on age, gender, and passenger class.
2.  **Data Preprocessing:** Handling missing values, feature encoding, and data cleaning.
3.  **Feature Engineering:** Creating new meaningful features to improve model accuracy.
4.  **Model Training:** Implementing and comparing various machine learning algorithms (e.g., Random Forest, Logistic Regression).
5.  **Evaluation:** Testing model performance using accuracy scores and confusion matrices.

---

### 🛠 Tech Stack

* **Language:** Python 3
* **Environment:** Jupyter Notebook
* **Libraries:**
    * **Pandas & NumPy:** For data manipulation.
    * **Matplotlib & Seaborn:** For data visualization.
    * **Scikit-learn:** For machine learning and preprocessing.

---

### 🚀 How to Run

1.  Clone the repository.
2.  Install the required libraries:
    ```bash
    pip install pandas numpy matplotlib seaborn scikit-learn
    ```
3.  Open the notebook:
    ```bash
    jupyter notebook "project_mel0104.ipynb"
    ```
4.  Run all cells to see the analysis and results.
